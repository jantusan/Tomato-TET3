# 3_RNAseq

This folder contains RNA-seq processing, differential expression analyses, and TEcount-based transposable element analyses.

## Contents

- `code/`: RNA-seq and TE integration notebooks (`01` to `08`) and SLURM scripts
- `reports/`: Rendered `.nb.html` notebook reports
- `data/`: intermediate and downstream RNA/TE tables generated by the notebooks

## RNA-seq TE pipeline reproducibility chain

`code/01.1_rnaseq_gene_processing.sbatch`
-> `code/01.2_rnaseq_STAR_multimapper_for_TE.sbatch`
-> `code/01.3_TEcount_analysis.sbatch`
-> `TEcount_output/<sample>.cntTable`
-> manual removal of the first line in each `.cntTable`
-> `data/4_counts/TEcounts/*.cntTable`
-> `code/06_TET3_RNAseq_TEcounts-scatter-PCAs.Rmd`, `code/07_TET3-RNAseq_TEcounts-DEGs.Rmd`, `code/08_TET3-RNAseq_TEs-DMRs.Rmd`

## Figure traceability

- RNA-seq gene-level exploratory and DE analyses are in code files `01` to `05`.
- TEcount downstream analyses are in code files `06` to `08`.
- An explicit manuscript figure export reference is present in code file `07` (e.g., `Figure4B` output naming).

## Final tables

- TEcount output tables are produced by `code/01.3_TEcount_analysis.sbatch` in `TEcount_output/`.
- The downstream TE notebooks expect cleaned `.cntTable` files in `data/4_counts/TEcounts/` together with the derived DESeq2 objects and result tables they generate.
